## Математическая постановка

### Ridge-регрессия
Минимизирует сумму квадратов ошибок с L2-регуляризацией:

$$
\min_{w, b} \sum_{i=1}^{n} (y_i - \hat{y}_i)^2 + \alpha \sum_{j=1}^{p} w_j^2
$$

где $\alpha$ — коэффициент регуляризации (в проекте $\alpha = 1.0$).

### PCA (Principal Component Analysis)
Находит ортогональные направления максимальной дисперсии. В проекте используется `n_components=0.95`, то есть сохраняется **95% объяснённой дисперсии**.

### KMeans-сегментация
Минимизирует внутрикластерную сумму квадратов:

$$
J = \sum_{i=1}^{k} \sum_{x \in C_i} \|x - \mu_i\|^2_2
$$

В проекте $k = 5$ сегментов рынка недвижимости.

### Поиск аномалий (Z-score)
Для остатков линейной регрессии `SalePrice ~ Gr Liv Area` вычисляется Z-score:

$$
z_i = \frac{r_i - \bar{r}}{\sigma_r}
$$

Аномалиями считаются объекты с $|z_i| > 3$.

## Пайплайн проекта

```
1. Ames Housing Dataset (80+ признаков)
2. Очистка пропусков:
   - категориальные - "None"
   - числовые (подвал, гараж) → 0
    - Для признака Lot Frontage используется двухэтапное заполнение: 
    сначала медианой по району (Neighborhood), а для районов, 
    где все значения пропущены, — общей медианой по датасету. 
    Это позволяет сохранить локальные особенности застройки, не теряя данные.
3. Feature Engineering:
   - Age at Sale (возраст дома)
   - Years Since Remodel (лет с ремонта)
4. One-Hot Encoding категориальных признаков
5. StandardScaler (Z-score нормализация)
6. Ridge-регрессия + топ-10 важных признаков
7. Поиск аномалий (Z-score остатков)
8. Сравнение R² до и после удаления аномалий
9. KMeans-сегментация (5 групп)
10. PCA (95% дисперсии) + LinearRegression
11. Анализ динамики цен: годы, месяцы, кризис 2008, сезонность
```

## Результаты

| Модель | R²      | Примечание                      |
|---|---------|---------------------------------|
| Ridge (до удаления аномалий) | *0.808* | `alpha=1.0`                     |
| Ridge (после удаления аномалий) | *0.915* | удалены объекты с  $\|z \| > 3$ |
| PCA (95%) + LinearRegression | *0.905* | снижение размерности            |


**Топ-признаки по модулю коэффициента Ridge :**
- `Gr Liv Area`
- `2nd Flr SF`
- `Overall Qual`
- `Total Bsmt SF`
- `BsmtFin SF 1 `

**Сегментация:** KMeans выделяет 5 групп по совокупности признаков (площадь, качество, год постройки, подвал, гараж). Распределение объектов по сегментам выводится в консоль.

**Динамика цен:**
- Средняя цена по годам продажи (`Yr Sold`).
- Средняя цена по месяцам (`Mo Sold`).
- Падение цен в кризис 2008: сравнение 2007 и 2009 годов.
- Сезонность: разница между весной (март–май) и зимой (декабрь–февраль).

## Реализовано вручную

- Очистка пропусков с учётом предметной области (заполнение `Lot Frontage` медианой по району, `NaN` в подвале/гараже → 0).

- Поиск аномалий через **Z-score остатков** линейной регрессии.
- Сравнение качества модели до и после удаления аномалий.
- KMeans-сегментация рынка на 5 групп.
- PCA с сохранением 95% дисперсии + LinearRegression.
- Анализ динамики цен: годы, месяцы, кризис 2008, сезонность.
